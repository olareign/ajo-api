# Security policy

Àjọ handles people's money and identity documents, so we treat security reports as a priority.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through GitHub:
**Security → Report a vulnerability** on this repository (private vulnerability reporting).

Include what you found, how to reproduce it and the impact you expect. We aim to:

| Step                        | Target                                       |
| --------------------------- | -------------------------------------------- |
| Acknowledge your report     | 2 working days                               |
| Confirm and assess severity | 5 working days                               |
| Fix critical or high issues | As fast as possible, normally within 14 days |

Please give us reasonable time to fix an issue before disclosing it, and do not access other people's data, run denial-of-service tests or use social engineering. Good-faith research within these limits will not be pursued legally.

## Scope

This API and the Àjọ web app ([olareign/Ajo](https://github.com/olareign/Ajo)). Third-party providers (KYC, payments, hosting) should be reported to them directly.
